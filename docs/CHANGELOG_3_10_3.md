# The Nook ePOS 3.11.0

## Responsive Payment UI and Order Review

- Cash payment reorganised into payment, customer/table and right-side action regions.
- Complete Sale and Cancel remain centred in a dedicated action column on wider screens.
- Layout automatically reflows for medium, portrait and phone-sized displays.
- Added compact Review Order button to Cash and Card payment screens.
- Review panel lists items, quantities, add-ons, notes, subtotal, discount and total.
- Back to Till closes payment without changing or losing the basket.
- No database schema or payment persistence changes.
