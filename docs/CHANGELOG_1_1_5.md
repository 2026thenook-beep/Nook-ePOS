# The Nook ePOS Browser 1.1.8

## Till screen simplification

- Removed the always-visible Server name field from the Till ticket panel.
- Removed the always-visible Table number field from the Till ticket panel.
- Removed the always-visible Customer name for receipt field from the Till ticket panel.
- The existing payment confirmation prompt remains responsible for collecting receipt/customer and table details.
- No transaction, report, kitchen, held-order or backend fields were removed.
