# Version 1.3.7 — Queued prompt option saves

- Prompt option edits are queued locally rather than requiring an individual save for every row.
- Each prompt has one Save option changes button with an unsaved-change count.
- Option reordering is queued with field changes and saved in the same operation.
- New options are queued and remain at the bottom until saved.
- Selecting another menu item, changing Menu Admin section, leaving Menu Admin, refreshing, or closing the browser warns about unsaved option changes.
- Choosing to discard restores the last server-loaded values and removes unsaved new options.
