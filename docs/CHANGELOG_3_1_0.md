# The Nook ePOS 3.1.0

## Till item-add feedback

- Each selected menu item remains a separate basket line.
- After an unconfigured item is added, the ticket panel intelligently scrolls only when the new line is outside the visible area.
- After a configured item is confirmed, the same feedback runs after the prompt modal closes.
- The newly added basket line briefly highlights.
- The Total to pay row briefly pulses.
- Quantity changes, deletions, tab changes and background synchronisation do not trigger the add feedback.
- Reduced-motion device preferences are respected.
