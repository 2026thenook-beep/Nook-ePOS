# Feature map from the uploaded feature list

## Till

- Category buttons.
- Item buttons with item price.
- Eat in / takeaway dropdown.
- Server name, table number and customer name fields.
- Prompt/add-on popups.
- Prompt quantities where `AllowValue` is enabled.
- Add-on totals are added to the item line.
- Add-on details are saved for ticket history, reports and kitchen display.
- Item-level notes from prompt setup.
- Full order note.
- Staff discount using Settings value.
- Cash/card payment.
- Cash paid and change due.
- Loyalty redeemed quantity so loyalty drinks and add-ons can be recorded without adding money.
- Hold order, clear order and complete transaction.

## Held

- Held orders can be restored to the till with add-ons/notes.
- Held orders are queued to the database.

## Reports

- Date range report.
- Total revenue.
- Cash/card totals.
- Refund totals.
- Loyalty drinks used.
- Top products.
- Sold by category.
- Sold by hour.
- Most popular add-ons.
- Least popular items.
- CSV export.

## Ticket History / Live Tickets

- Loads local tickets and can refresh from database.
- Search by ticket/customer/table.
- View full order including add-ons.
- Reload ticket to till.
- Refund ticket lines.
- Browser print option.

## Refunds

- Refund records are saved separately.
- Refunds deduct from Reports.

## Kitchen

- Shows ticket number, customer/table/server.
- Splits food and drink.
- Complete food and complete drinks separately.
- Shows add-ons and item notes.
- Order complete stamp and removal delay.
- Status update queues back to database.

## Menu Admin

- Add/edit/remove categories.
- Add/edit/remove menu items.
- Edit active/show-on-till/loyalty settings.
- Add/edit prompts and prompt options.
- Set prompt type, required, sort order and notes.
- Set option price and quantity/AllowValue.

## Settings

- Save/test Apps Script URL.
- Saved URL list.
- Printer settings area.
- Staff discount setting.
- Database builder/repairer.
- Version/system info.
- Backup and restore.
- Offline mode toggle.

## Sync

- Local queue.
- Read/write status.
- Sync log with errors.
- Manual sync button.
