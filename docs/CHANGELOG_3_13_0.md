# 3.13.0 — Menu Administration Overhaul

- Removed the misleading Ticket / #saving panel from Payment Complete.
- Retained cash received and prominent change display.
- Added guided pop-out creation workflows for menu items, prompts and categories.
- Added required-field, duplicate-name and price validation.
- Added fixed pound prefixes to item and prompt-option price inputs.
- Renamed and strengthened Duplicate Prompts workflow.
- Duplicate Prompts retrieves the latest source configuration from the server before confirmation.
- Added visible waiting overlays for prompt loading, duplication and server confirmation.
- Retained protected Menu Admin edit state, local-first payments, Kitchen revision polling and blank-screen containment.
- Draft/publish mode was deliberately not introduced.
