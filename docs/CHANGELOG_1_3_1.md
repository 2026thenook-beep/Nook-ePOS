# The Nook ePOS 1.3.1 — Save and Recall Status Messages

- Shows a blocking **Loading — Please wait** message while a held order is recalled and removed from Google Sheets.
- Shows a blocking **Saving — Please wait** message while a Menu Admin item is saved.
- Shows the same saving message while an item prompt is saved.
- The overlay closes on both success and failure so staff are never left on a locked screen.
- Existing internal routes, data tables and Apps Script actions are unchanged.
