# The Nook ePOS 1.3.2

## Saving status coverage

The blocking **Saving — Please wait** message now appears while:

- saving a prompt option;
- saving a category;
- processing an item-level refund;
- saving and testing the Google Apps Script URL in Settings.

The overlay closes after successful completion and after errors.

If a refund save fails, the refund form is restored with the selected quantities, reason and staff name retained so the user can correct or retry it.
