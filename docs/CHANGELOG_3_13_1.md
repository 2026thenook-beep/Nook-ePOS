# 3.13.1 — Till Menu Layout Editor

Rebuilt from the 3.13.0 Menu Administration Overhaul.

- Adds **Edit menu layout** directly to the Till.
- Uses the real Till category strip and item grid as the arrangement canvas.
- Supports drag-and-drop and arrow controls.
- Hides payment controls while editing.
- Saves all category and item Sort values in one protected server write.
- Cancel restores the pre-edit arrangement.
- Does not include the discarded separate three-column arrangement screen.
