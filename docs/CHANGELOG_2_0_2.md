# The Nook ePOS 2.0.3

## Prompt option drag-and-drop

- Prompt options can be reordered by dragging the handle on each row.
- Pointer-based handling supports mouse, touch and stylus input.
- Reordering remains queued until **Save option changes** is selected.
- After a successful save, prompt data is reloaded from Google Sheets so the screen shows the authoritative saved order.
- Unsaved edits belonging to other prompts are preserved during the reload.

Frontend and backend: 2.0.3. Database schema: 1.0.6.
