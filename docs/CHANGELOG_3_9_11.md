# The Nook ePOS 3.9.11

## Card payment
- Added a prominent CARD PAYMENT amount panel to the card confirmation screen.
- The required card amount now uses the same font size, weight and focal position as the Cash CHANGE panel.
- Retained the existing customer name, table number, Back and Confirm Card Payment controls.

## Compatibility
- Cash quick tender buttons and cash calculations are unchanged.
- Eat In / Takeaway recovery from 3.9.10 is unchanged.
- This is the final focused UI release before the planned 3.10.0 patch merge.
