# 3.13.3 — Differential Menu Admin Save

- Item configuration saves now calculate a field-level patch against the confirmed baseline.
- Only changed item, prompt and option fields are sent.
- Removed prompts/options are explicitly listed and deleted.
- Category and standalone item saves send field-level patches.
- Google Apps Script updates only affected cells rather than rewriting complete menu sheets.
- Server confirmation remains mandatory after item configuration saves.
