# The Nook ePOS Browser 1.1.4

## Kitchen display

- Added an **Open Food** ticket count beside **Refresh from server**.
- Added an **Open Drinks** ticket count beside **Refresh from server**.
- Counts update automatically with the existing Kitchen polling cycle.
- Counts represent open ticket sections, not item quantities.
- A ticket with completed food and open drinks contributes only to the drinks count.
- Fully completed tickets are excluded from both counts.
- Added responsive styling for tablets and phones.

## Versioning

- Frontend and backend versions updated to 1.1.4.
- Database version remains 1.0.6.
