# The Nook ePOS 3.8.5

## Guided Eat In / Takeaway selection

- Shows a themed Eat In / Takeaway popup whenever the Till tab is selected without an order type.
- Allows the opening popup to be cancelled.
- If the first menu item is tapped while no order type is selected, the item is held pending and the popup is shown again.
- The pending item is added only after Eat In or Takeaway is selected; cancelling leaves the basket unchanged.
- After a confirmed payment summary is closed, the next-order popup opens automatically.
- Held and recalled orders retain their saved order type.
- Uses the existing OrderType field throughout tickets, kitchen, receipts, history and reports.
