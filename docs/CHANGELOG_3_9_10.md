# The Nook ePOS 3.9.10

## Cash payment
- Added quick cash received buttons for £10, £20, £30, £40 and £50.
- Quick buttons replace the tendered value and immediately recalculate Still to Pay, Exact Payment or Change.
- Retained the Exact amount shortcut and manual auto-decimal keypad.

## Eat In / Takeaway
- Restored the guided order-type prompt during initial startup, reconnection and return to an empty Till.
- Added a guarded scheduler so the prompt does not overwrite payment, item or recovery dialogs.
- First-item and post-payment order-type safeguards remain active.
