# The Nook ePOS Browser 1.1.4

## Till prompt selection
- Standard radio and checkbox prompt options can now be selected by tapping anywhere on the option card.
- Options using variable quantity controls retain separate minus, quantity and plus controls to prevent accidental selections.
- Selected standard choices receive a visual highlight on compatible browsers.

## Till independent scrolling
- The menu-item grid now scrolls independently inside the left Till panel.
- The ticket details (order type, server, table and customer) remain visible at the top of the right Till panel.
- The ticket lines, totals and payment controls scroll independently beneath those details.
- Responsive height limits are included for desktop, tablet, phone and landscape layouts.

## Version
- Frontend: 1.1.4
- Backend: 1.1.4
- Database: 1.0.6
